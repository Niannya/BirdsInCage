# 宅邸：已确定背景、当前布局与地图待办

## 已确认的故事事实
- 宅邸位于狄赛珂丝村附近的森林中，原本是菲洛梅尔与父母生活的房子。
- 父母严格限制菲洛梅尔外出；她主要与玩偶相伴。
- 魔女放火焚毁过宅邸，之后**宅邸被魔法恢复，整体基本保持原样**。
- 魔女把宅邸变成了能囚禁、折磨人的魔法空间。
- **宅邸不设置佣人**，不要设计佣人房、佣人事件或照顾菲洛梅尔的佣人角色作为既定设定。
- 三楼菲洛梅尔的房间在已有剧情中是重要终点场景。
- 有一处偶然/随机出现的露台，通往魔女花园；菲洛梅尔此前也没有进去过。

## 已确认的建筑方向
- 宅邸规模为**中型贵族宅邸**；早期“小型宅邸”的说法已经被用户明确更正。
- 时代方向为 19 世纪，倾向 19 世纪中后期的欧洲乡间宅邸。
- 英国乡间住宅可以作为参考，但尚未指定具体国家或严格建筑流派。
- 宅邸整体仍倾向约三层，菲洛梅尔房间位于三楼；各层的精确定义仍待设计。

## 当前一层概念布局
最新概念草图见 [`References/first_floor_sketch_latest.png`](References/first_floor_sketch_latest.png)。草图用于确定空间关系，不是按比例绘制的最终建筑图。

- **中央大厅**位于建筑中央偏南，南侧是主入口；它是宽敞的主要空间，不只是狭窄门厅。
- 大厅东侧黄色弧形结构表示类似飘窗的向外凸出窗体，当前暂称**弧形凸窗**；其严格建筑术语和立面形式尚未定稿。
- **客厅**位于大厅西南侧，承担较正式的会客功能，并与东北侧供家庭日常活动的**起居室**明确区分。
- **餐厅**位于西北侧并与厨房相邻；草图中有门通往西侧花园。
- **厨房**位于西北角并设有室外门。
- **起居室**位于东北侧并有门通往后院。
- 花园和后院分别标示；二者是否相连尚未决定。

## 楼梯决定
- 大厅北侧的**主楼梯**当前被隐藏、伪装成墙壁。
- **次级楼梯**位于厨房右侧的独立小楼梯间，不直接设置在厨房内。
- 起居室中的楼梯已经删除，除非用户以后明确改变决定，否则不要加回。
- 主楼梯为何及何时被隐藏、如何显现，以及次级楼梯通往何处，目前都不能自行补写。

## 当前未知
- 宅邸的确切国家/文化参照、具体年代与严格建筑风格。
- 三层究竟如何定义（完整第三层、阁楼、塔楼等）。
- 一层房间的精确尺寸、门窗、家具和最终通道；其他楼层的房间数量与用途。
- 大厅东侧弧形凸窗的准确术语、尺寸、高度、窗格和外立面构造。
- 各空间的谜题与剧情放置。
- 魔法恢复前后有多少看得见的异变，以及如何在探索中体现。
- 露台出现的触发条件。

## 地图设计原则
垂直切片当前只实现从南侧入口进入大厅、在大厅解谜并进入西南客厅的最小流程。一层其他空间可以帮助维持建筑关系，但不因此成为可探索内容。不要为“真实贵族建筑”硬塞佣人设定；也不要把概念草图直接当作最终比例图或未经讨论就扩展完整宅邸。
