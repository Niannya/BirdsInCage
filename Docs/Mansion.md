# 宅邸：已确定背景与地图待办

## 已确认的故事事实
- 宅邸位于狄赛珂丝村附近的森林中，原本是菲洛梅尔与父母生活的房子。
- 父母严格限制菲洛梅尔外出；她主要与玩偶相伴。
- 魔女放火焚毁过宅邸，之后**宅邸被魔法恢复，整体基本保持原样**。
- 魔女把宅邸变成了能囚禁、折磨人的魔法空间。
- **宅邸不设置佣人**，不要设计佣人房、佣人事件或照顾菲洛梅尔的佣人角色作为既定设定。
- 三楼菲洛梅尔的房间在已有剧情中是重要终点场景。
- 有一处偶然/随机出现的露台，通往魔女花园；菲洛梅尔此前也没有进去过。

## 暂定方向（不是建筑平面图定稿）
- 最近讨论过：乡间规模较小的西式贵族宅邸、约三层，菲洛梅尔房间在三楼。
- 还讨论过历史上较常见的中央门厅、公共房间、私人楼层及厨房后勤分区；这些只是建筑参考，**没有获准为正式布局**。

## 当前未知
- 宅邸的国家/文化参照、建造年代、建筑风格。
- 三层究竟如何定义（完整第三层、阁楼、塔楼等）。
- 各层房间数量、用途、具体通道及谜题放置。
- 魔法恢复前后有多少看得见的异变，以及如何在探索中体现。
- 露台出现的触发条件。

## 地图设计原则
先按切片需要实现**少量互联房间**，验证探索和谜题循环。不要为“真实贵族建筑”硬塞佣人设定；也不要未经讨论就绘制全宅邸最终地图。
