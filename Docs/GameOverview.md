# Game overview

## 已知方向
- 名称：**BirdsInCage**。
- 类型/视角：**2D 俯视角恐怖解谜 RPG 风格游戏**。
- 侧重：叙事、宅邸探索、解谜、记忆与多结局；参考气质曾提到《魔女之家》，但故事为独立创作。
- 当前目标：**先做一个可玩切片（vertical slice）**，不要求现在锁定全游戏所有房间和谜题。

## 已确定的垂直切片范围
- 开始：玩家由南侧主入口进入宅邸。
- 主体：玩家在中央大厅探索并完成一个尚待设计的谜题。
- 结束：玩家成功进入大厅西南侧的客厅。
- 可探索空间目前只包含大厅和客厅。一层其他房间是整体布局参考，不自动进入切片制作范围。
- 大厅和客厅分别使用独立的 Unity Scene，并通过门进行场景切换；后续宅邸主要房间也按独立场景组织。

## 核心体验（概述）
玩家操作失去部分记忆的瑞茵，重新踏入魔女之家，逐渐找回与阿洛缇的过往、发现菲洛梅尔的遭遇，最终做出会影响命运的行动。

## 当前开发环境
- Unity 2022.3.62f2 LTS。
- Universal Render Pipeline 14.0.12，使用 2D Renderer。
- 当前输入来自旧版 Input Manager。
- 已完成玩家移动、跑步、2D 碰撞、基础摄像机控制，以及 Hall/Parlor 双向场景切换和按门选择出生点的原型验证；这些仍属于灰盒阶段，不代表最终表现。
- 用户正在学习 Unity，并亲自进行主要编辑器操作和脚本编写；Codex 以解释、检查和按需提示为主。

## 当前阶段不应预设
- 宅邸全部房间的功能与地图没有定稿。
- 切片谜题、叙事文本、进入客厅后的收束形式和完成判定细节没有定稿。
- 场景切换时的画面过渡和跨场景游戏状态保存方式没有定稿；按门选择出生点的基础规则已经验证。
- 玩法系统和美术资源的最终实现方式没有定稿。
