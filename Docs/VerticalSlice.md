# 垂直切片计划（待确定范围）

## 已确认目标
先制作一个**可玩垂直切片**，用小范围展示本游戏的探索、氛围、解谜与叙事方式。无需先把宅邸整个布局及全章节脚本定稿。

## 以下是实施建议，尚未确认
建议从**一个短流程**开始：进入一个宅邸局部空间 → 在有限房间内探索并获得线索 → 解开一项与人物/环境相关的谜题 → 触发一次有意义的叙事反馈 → 达到切片结束点。

建议技术上先验证：
1. 2D 俯视角移动、碰撞、场景切换；
2. 观察/调查物品、简短文本交互；
3. 简单道具与条件判定；
4. 一次谜题反馈及收束；
5. 可运行构建与最基本的保存/加载（若切片确需）。

以上只是候选范围，**不要擅自认定入口、谜题、房间或剧情节点**。

## 切片开工前应确认
- 从哪一个场景开始、在哪个事件结束？
- 选哪一个最能表现游戏特点的谜题？
- 需要多少可进入房间？
- 是否展示主线剧透或只展示较独立的局部经历？
- 当前 Unity 工程有哪些已经实现的能力？

## 建议开发节奏
先调查现有工程 → 做最低限度可玩闭环 → 游戏内测试 → 补充气氛、文本、反馈 → 固定一个可演示版本。每阶段用 Git 提交，不要一次开发整个游戏。
