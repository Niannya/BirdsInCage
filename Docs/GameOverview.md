# Game overview

## 已知方向
- 名称：**BirdsInCage**。
- 类型/视角：**2D 俯视角恐怖解谜 RPG 风格游戏**。
- 侧重：叙事、宅邸探索、解谜、记忆与多结局；参考气质曾提到《魔女之家》，但故事为独立创作。
- 当前目标：**先做一个可玩切片（vertical slice）**，不要求现在锁定全游戏所有房间和谜题。

## 核心体验（概述）
玩家操作失去部分记忆的瑞茵，重新踏入魔女之家，逐渐找回与阿洛缇的过往、发现菲洛梅尔的遭遇，最终做出会影响命运的行动。

## 开发环境需现场检查
用户打算在 Unity / Codex 工作流继续；但**尚未检查实际 Unity 工程**，因此这里不宣称已确定的 Unity 版本、Input System、渲染管线、目录组织或已有代码功能。

## 当前阶段不应预设
- 切片具体起止点、房间数量、完成标准还没有定稿。
- 宅邸全部房间的功能与地图没有定稿。
- 玩法系统、谜题和美术资源的最终实现方式没有定稿。
