- 阿洛缇与瑞茵在湖边与小猫玩，湖心岛上长有一颗小嘲树（或称反舌树，mockingtree）。嘲树模仿瑞茵的哭声，瑞茵很惊讶，阿洛缇向她讲解这种树。嘲树在幼小时能够模仿周围的声音来驱赶进入它领地的生物，但长大后就逐渐沉默，取而代之的是用它粗壮的树枝攻击周围的生物。嘲树生长能力很强，根系与大地结合很紧密。成树及其高大，不仅会夺取大片土地的养分，还会遮蔽阳光，是一种害树。要彻底杀死一颗嘲树，光是砍倒刨根远远不够，还要用火烤它生长过的土地，否则它遗留在土壤中的种子还会再度生根发芽。
- 阿洛缇与瑞茵将嘲树的存在报告给了大人们，于是他们砍掉了这棵尚小的嘲树。就在大人们用火烤地时，阿洛缇和瑞茵带来的小猫受了惊，不小心掉进了湖里，而大人们都专注于工作没有注意到她们的呼救。瑞茵很伤心。
- 阿洛缇与瑞茵从小伙伴们那里听来了魔女之家的消息，于是阿洛缇提议去那里寻找魔女复活小猫。
- 以上是游戏开场剧情，随后瑞茵惊醒。（此时她的精神问题极其严重，已经忘了自己与姐姐的名字，在剧情中提到名字的地方需做模糊处理。）玩家操控她在村子里探索，会捡到一张**报纸残片**，上面是魔女被处刑的新闻。
- 瑞茵独自一人回到那个湖边，她无法忍受失去姐姐的现状，无法原谅对此无能为力的自己。她决定结束自己的生命。但就在那里遇到了一个阿洛缇的熟人，那个人惊讶于阿洛缇性格的转变。正是因为此，瑞茵想起了阿洛缇的名字，对姐姐的思念制止了她。瑞茵想在姐姐身边死去，于是前往宅邸。
- 瑞茵探索宅邸时，会见到很多阿洛缇与菲洛梅尔交流的小纸条（阿洛缇与瑞茵有时也会通过纸条交流）。随着探索她想起了越来越多与姐姐的记忆。
- 瑞茵在三楼菲洛梅尔的房间里终于见到了菲洛梅尔与姐姐。
- 宅邸中有个露台，是随机出现的，即使是菲洛梅尔也没进去过。那里是魔女的花园。那里有着一棵高大的嘲树，以及一个巨人（玩家进入露台后，只能看到巨人的脚）。那个巨人是魔女抓来的园丁。
- 瑞茵得知魔女的一个核心在宅邸中，只要那个核心存在，宅邸里的魔法就不会失效（同时菲洛梅尔就永远无法离开宅邸，这个信息不被直接透露，但菲洛梅尔是被魔法囚禁的，可以从这里推出）。
- 瑞茵得到了有关核心的提示，玩家需要辨别出核心，然后破坏。
- 对魔女的恐惧与顺从已经根植在菲洛梅尔的心，若玩家持有**报纸残片**并在最后展示给菲洛梅尔，她就会与瑞茵一同离开。若没有破坏核心，魔女会在最后现身。她允许菲洛梅尔离开，但有一个要求，让菲洛梅尔跟在瑞茵身后，而瑞茵在离开宅邸的过程中绝对不能回头。（玩家需要从三楼回到门口，这时只有瑞茵身边能看清，刚好能看清她们牵着的手。在三层时播放一些音效，二层后就不发出任何声音，包括脚步声。在一层时看不见菲洛梅尔的手，但瑞茵的姿势仍保持不变。）若瑞茵回头了，她会被永远留在这里（结局C，Cage）。若瑞茵没有回头直接离开，出去后她终于回头，发现自己牵着的是魔女。在这个结局里，魔女夺舍了瑞茵的身体。（结局D，Demon）
- 若破坏了真的核心，魔女则不再出现。瑞茵与菲洛梅尔逃出宅邸，然而此时阿洛缇仍在菲洛梅尔身体里。在游戏开头玩家在村子里调查时，若见到她，则她会说瑞茵的灵魂混有不纯之物，同时又缺失了一部分。让瑞茵带着另一半灵魂回来，她会帮忙使瑞茵圆满。逃出宅邸后返回这里，狄赛珂丝会说，瑞茵的灵魂仍然不纯，很可能会失败。若玩家在此时做出了正确的行动，则姐妹终于重聚，她们三人幸福地生活在一起。（结局E，End）若开头没见到狄赛珂丝或在此时没有做出正确行动，则失败，阿洛缇仍然在菲洛梅尔身体里。（结局A，Alice）
- 探索过程中可随时离开宅邸。若瑞茵离开宅邸，或以上结局均未达成，则瑞茵独自逃离宅邸，魔女复活后会夺舍她的身体。（结局B，Betrayer）
