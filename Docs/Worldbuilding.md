# 世界观

## 狄赛珂丝与深渊
- **狄赛珂丝（Diphychos）**：深渊附近的村子，也是此界和彼界之间唯一的通道所在。
- 彼界穿过深渊来到此界的灵魂，会寄宿到当地居民身上。
- 村庄据传以原先居住于此的贤者命名；相关贤者在后段剧情中扮演重要角色。

## 魔女与宅邸
- 魔女是早期越过深渊者之一，以折磨他人为乐；曾被通缉，后来隐匿行踪。
- 她接近森林宅邸中的菲洛梅尔，与她交友并教她小魔法，随后焚毁宅邸、嫁祸菲洛梅尔，将其囚禁和折磨。
- **近期确认**：宅邸曾被魔法恢复，恢复后整体基本保留原来形制。不是任意新造的纯粹迷宫。
- 宅邸同时是魔女用来折磨菲洛梅尔的魔法刑具；此前误入者成为游魂。菲洛梅尔经历反复死亡与复活。
- 故事开始时，魔女已被处刑，但其魔法的延续及结局依赖宅邸内的核心。

## 嘲树（mockingtree，亦称反舌树）
- 幼树能模仿附近声音，驱赶进入领地的生物。
- 成树不再主要模仿声音，能用巨枝攻击生物；体型巨大，夺走养分、遮蔽日光。
- 根系顽强，单纯砍倒挖根不能彻底消灭；须用火处理生长过的土地，以免种子再次萌发。
- 湖心岛的幼树与小猫溺亡事件关联；魔女花园中另有一棵高大嘲树。
